**Structural Strength**: The paper embeds bilateral shipping-time shocks and cross-border input-output propagation in a parsimonious Eaton-Kortum/Caliendo-Parro environment. The hat-algebra formulation makes a large 107-region, 31-sector counterfactual computationally feasible and clearly separates gross real-income gains from the assumed fiscal cost of infrastructure.

**Domain Audit**: The displayed goods-market equilibrium is not consistent with the production technology's indexing. The manuscript defines gamma_n^{jk} as the share of input sector k used by output sector j in country n. Demand for sector-j composites by country-n producers must therefore sum gamma_n^{kj} over output sectors k. Equation (10), however, uses gamma_n^{jk}. Unless the input-output matrix is symmetric, which is neither assumed nor economically plausible, this transposes the required mapping and assigns intermediate demand using the wrong coefficients. Annex equation (A4) repeats the problem and additionally introduces an undefined consumption tax tau_n^C. Because equations (10)/(A4) close the goods markets, this is not merely cosmetic: if the simulations implemented the displayed system, all reported GDP, welfare, and trade counterfactuals are generated by the wrong production network. If the code instead uses gamma_n^{kj}, the manuscript must correct the equations and document that correspondence. A second, related closure issue requires clarification: infrastructure costs enter only as a household tax that disappears from the resource constraint, with no government construction demand, transfer recipient, or explicit external payment. This can represent an equivalent variation or pure resource loss, but not literally a domestically financed construction sector without further accounting. The welfare results should be interpreted accordingly or the fiscal/resource closure should be completed.

**Best-Case Contribution**: The strongest credible contribution is a quantitatively tractable framework for evaluating permanent changes in an international transport network, including indirect input-output spillovers, together with a detailed BRI application that maps proposed links into bilateral sector-specific trade-cost changes and compares resulting real-income gains with an annualized project-cost allocation.
